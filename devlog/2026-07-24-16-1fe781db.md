# Security Update: BlueNoroff Zoom Phishing Kit Profiles Crypto Wallets Before Malware Delivery

_2026-07-24 16:36 UTC_

[Source](https://thehackernews.com/2026/07/bluenoroff-zoom-phishing-kit-profiles.html)

**Devlog Entry: BlueNoroff Zoom Phishing Kit**

**Date:** 24 July 2026

**Summary:**
The BlueNoroff Zoom phishing kit has been identified as a sophisticated threat capable of profiling crypto wallets before delivering malware. This kit exploits Zoom's APIs to gather sensitive information and target users with tailored phishing attacks. Developers should be cautious when integrating Zoom APIs and implement robust security measures to prevent unauthorized access to user data.
