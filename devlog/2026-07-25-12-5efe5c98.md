# Security Update: Cl0p Affiliates Target Internet-Exposed PTC Windchill and FlexPLM with Unauthenticated RCE

_2026-07-25 12:17 UTC_

[Source](https://thehackernews.com/2026/07/cl0p-affiliates-target-internet-exposed.html)

**Devlog Entry: Cl0p Affiliate Vulnerability (2026-07-25)**

* **Threat Summary:** Cl0p affiliates have been exploiting unauthenticated Remote Code Execution (RCE) vulnerabilities in PTC Windchill and FlexPLM systems exposed to the internet. This attack vector allows attackers to execute arbitrary code without authentication, highlighting the importance of patching and securing exposed systems.
* **Recommendation:** Review and apply security patches for PTC Windchill and FlexPLM installations, and ensure that all systems exposed to the internet are regularly monitored and updated to prevent similar exploitation.
