# Security Update: Fastjson 1.x RCE Vulnerability Targeted in Attacks With No Patched Available

_2026-07-25 13:37 UTC_

[Source](https://thehackernews.com/2026/07/fastjson-1x-rce-vulnerability-targeted.html)

**Devlog Entry: FastJSON 1.x RCE Vulnerability**

* **Date:** 25 July 2026
* **Summary:**
FastJSON 1.x has been targeted in attacks due to a Remote Code Execution (RCE) vulnerability. This exploit takes advantage of a known issue with the library's deserialization process, allowing attackers to execute malicious code. Given the widespread adoption of FastJSON in various projects, it is essential to assess and address this vulnerability to prevent potential security breaches.
