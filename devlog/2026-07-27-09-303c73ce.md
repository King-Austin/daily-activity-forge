# Security Update: GitHub Adds 3-Day Dependabot Cooldown to Limit Poisoned Package Adoption

_2026-07-27 09:41 UTC_

[Source](https://thehackernews.com/2026/07/github-adds-3-day-dependabot-cooldown.html)

**Devlog Entry: GitHub Dependabot Cooldown Update**

**Date:** July 2026

* **Update:** GitHub has implemented a 3-day cooldown period for Dependabot updates to mitigate the adoption of poisoned packages.
* **Impact:** This change aims to reduce the rapid spread of malicious dependencies, allowing developers more time to review and validate updates before adopting them.
* **Insight:** This update highlights the importance of dependency management and the need for developers to be cautious when adopting updates, even from trusted sources like Dependabot.
