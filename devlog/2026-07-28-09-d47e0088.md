# Security Update: Critical TeamCity Flaw Could Let Attackers Run OS Commands Without Logging In

_2026-07-28 09:24 UTC_

**Devlog Entry: Critical TeamCity Flaw (2026-07-2026)**

A critical security vulnerability in TeamCity has been discovered, allowing attackers to execute arbitrary OS commands without authentication. This flaw, if exploited, could enable attackers to escalate privileges, extract sensitive data, or disrupt system operations. It is essential to update TeamCity to the latest version to prevent potential exploitation of this critical flaw.
