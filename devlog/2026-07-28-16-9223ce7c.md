# Security Update: 24,650 Internet-Exposed BMCs Disclose IPMI Password Hashes Before Login

_2026-07-28 16:05 UTC_

[Source](https://thehackernews.com/2026/07/24650-internet-exposed-bmcs-disclose.html)

**Devlog Entry: Exposed BMCs and IPMI Password Hashes**

Date: 28 July 2026

**Summary**

A recent cybersecurity update revealed that 24,650 Internet-exposed Baseboard Management Controllers (BMCs) are disclosing IPMI password hashes before login, potentially exposing sensitive system credentials. This vulnerability highlights the importance of secure configuration and monitoring of BMCs, which are often overlooked in security audits. Organizations should review their BMC configurations and implement additional security measures to prevent unauthorized access.
