# Security Update: Two Compromised joyfill npm Packages Run RAT When Imported Into Node.js

_2026-07-29 04:47 UTC_

[Source](https://thehackernews.com/2026/07/two-compromised-joyfill-npm-packages.html)

**Devlog Entry: Security Alert - Compromised joyfill npm Packages**

*Date: 29 July 2026*

**Summary:** Two compromised `joyfill` npm packages, `@joyfill/clipboard` and `@joyfill/keyboard`, have been reported to run a Remote Access Trojan (RAT) when imported into a Node.js project. This potential threat highlights the importance of carefully reviewing dependencies and keeping software up to date to prevent malicious code execution. Developers are advised to audit their dependencies and remove these compromised packages immediately.
