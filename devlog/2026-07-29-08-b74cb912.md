# Security Update: Flying Eagle Android RAT Traces Found on 170 Servers as Source Code Circulates

_2026-07-29 08:07 UTC_

[Source](https://thehackernews.com/2026/07/flying-eagle-android-rat-traces-found.html)

**Devlog Entry - 29 July 2026**

### Potential Threat: Flying Eagle Android RAT

* **Summary:** Recent reports suggest the presence of 'Flying Eagle' Android Remote Access Tool (RAT) on 170 servers, with the source code circulating online. This malware is designed to grant attackers unauthorized access to compromised devices.
* **Implications:** As the source code is publicly available, threat actors may leverage it to create more sophisticated variants of the malware, exacerbating the risk of widespread exploitation.
