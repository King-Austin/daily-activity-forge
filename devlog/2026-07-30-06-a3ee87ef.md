# Security Update: Cisco FMC Zero-Day Actively Exploited, Static Credentials Could Expose Sensitive Data

_2026-07-30 06:09 UTC_

[Source](https://thehackernews.com/2026/07/cisco-fmc-zero-day-actively-exploited.html)

**Devlog Entry: July 30, 2026**

### Cisco FMC Zero-Day Vulnerability

A zero-day vulnerability in Cisco Firepower Management Center (FMC) has been actively exploited, allowing unauthorized access to sensitive data. This vulnerability is particularly concerning due to the potential for attackers to exploit static credentials stored within the system. Remediation and immediate patching are recommended for all FMC installations to prevent potential data breaches.
