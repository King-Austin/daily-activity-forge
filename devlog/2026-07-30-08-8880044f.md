# Security Update: Russian Hackers Exploit Microsoft OWA Flaw to Keep Mailbox Access After Credential Rotation

_2026-07-30 08:09 UTC_

[Source](https://thehackernews.com/2026/07/russian-hackers-exploit-microsoft-owa.html)

**Devlog Entry: Microsoft OWA Flaw Exploitation**

* Date: 30 July 2026
* Reference: [https://thehackernews.com/2026/07/russian-hackers-exploit-microsoft-owa.html](https://thehackernews.com/2026/07/russian-hackers-exploit-microsoft-owa.html)
* Summary:
Russian hackers have been exploiting a vulnerability in Microsoft's Online Web Application (OWA) that allows them to maintain access to a mailbox even after credential rotation. This exploit takes advantage of a previously unknown weakness in the OWA system, which enables hackers to circumvent security measures and maintain unauthorized access. Organizations using Microsoft OWA should prioritize patching and implementing additional security measures to mitigate this threat.
