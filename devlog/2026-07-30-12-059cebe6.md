# Security Update: Microsoft Copilot for Word Can Copy Hidden Prompts Into New Documents

_2026-07-30 12:50 UTC_

[Source](https://thehackernews.com/2026/07/microsoft-copilot-for-word-can-copy.html)

**Devlog Entry - 2026-07-30**
### Microsoft Copilot for Word Vulnerability

A recent security update has revealed that Microsoft Copilot for Word can potentially copy hidden prompts into new documents. This issue arises from the model's ability to learn and replicate user input, even if it is not explicitly visible in the interface. This vulnerability highlights the importance of carefully evaluating AI-powered tools for potential security risks.
