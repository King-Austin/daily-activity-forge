# Security Update: 18 Malicious npm Packages Deliver Cross-Platform RAT to Alibaba Tool Users

_2026-08-03 19:03 UTC_

[Source](https://thehackernews.com/2026/08/18-malicious-npm-packages-deliver-cross.html)

**Devlog Entry: npm Package Security Threat**

**Date:** August 3, 2026

**Summary:** 18 malicious npm packages were discovered to be delivering a cross-platform Remote Access Trojan (RAT) to users of the Alibaba tool, highlighting the ongoing threat of package hijacking and supply chain attacks in the JavaScript ecosystem. This incident serves as a reminder of the importance of scrutinizing package dependencies and employing secure development practices. Developers are advised to regularly audit their dependencies and ensure they are using reputable package sources.
