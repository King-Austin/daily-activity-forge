# Security Update: Google Deletes 3 ADK AI Workflows After Malicious GitHub Issue Could Trigger Privileged Agent

_2026-08-04 13:24 UTC_

[Source](https://thehackernews.com/2026/08/google-deletes-3-adk-ai-workflows-after.html)

**Devlog Entry - August 4, 2026**

**Security Alert: Google ADK AI Workflows**

Google has deleted 3 ADK AI workflows after a malicious GitHub issue was discovered to be capable of triggering a privileged agent, highlighting the potential for untrusted code execution in software supply chains. This incident demonstrates the importance of monitoring and validating contributed code to prevent unintended access to sensitive resources. This vulnerability serves as a reminder of the critical role of secure coding practices in mitigating the risks associated with open-source dependencies.
