# Security Update: Keyv-Linked npm Worm Poisons Hundreds of Packages, Plants Claude Code and VS Code Hooks

_2026-08-04 14:25 UTC_

[Source](https://thehackernews.com/2026/08/keyv-linked-npm-worm-poisons-hundreds.html)

**Devlog Entry: Keyv-Linked npm Worm**

On August 2026, a critical cybersecurity threat has been identified involving a Keyv-linked npm worm that has compromised hundreds of packages, introducing malicious code and hooks into popular development tools such as Claude and Visual Studio Code (VS Code). This threat highlights the importance of maintaining secure package dependencies and implementing robust security measures to prevent malicious packages from being installed and executed. Developers are advised to review their dependencies and update to the latest versions to mitigate potential risks.
