### Greatness PhaaS Adds Device Code Phishing to Bypass MFA and Steal Tokens

A recent update to the Greatness PhaaS toolset has introduced a new phishing tactic that targets device code verification, potentially allowing attackers to bypass multifactor authentication (MFA) and steal authentication tokens. This development underscores the evolving nature of phishing attacks and the need for robust security measures to protect against device code verification-based exploits.
