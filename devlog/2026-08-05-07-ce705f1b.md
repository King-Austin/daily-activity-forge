# Security Update: QuickFox Supply Chain Attack Delivers FDMTP Backdoor via Trojanized Windows Installer

_2026-08-05 07:07 UTC_

[Source](https://thehackernews.com/2026/08/quickfox-supply-chain-attack-delivers.html)

**Security Update: QuickFox Supply Chain Attack**

*Date*: 05 August 2026
*Source*: The Hacker News
*Severity*: High

Summary:
A recent supply chain attack targeting QuickFox software has been identified, delivering a FDMTP (Fast Distributed Malware Transmission Protocol) backdoor via a Trojanized Windows installer. This attack vector exploits vulnerabilities in the software update mechanism, allowing malicious actors to inject malware into unsuspecting systems. Developers and users are advised to exercise extreme caution when downloading and installing software from untrusted sources.
