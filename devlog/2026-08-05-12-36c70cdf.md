# Security Update: New OVSwrap Linux Kernel Flaw Lets Local Users Gain Root via Open vSwitch

_2026-08-05 12:47 UTC_

[Source](https://thehackernews.com/2026/08/new-ovswrap-linux-kernel-flaw-lets.html)

**Devlog Entry: OVSwrap Linux Kernel Flaw (2026-08)**

A newly discovered vulnerability in the Linux kernel, specifically affecting Open vSwitch (OVS) via the OVSwrap mechanism, allows local users to gain root privileges. This flaw, found in kernel versions prior to version 5.19.1, enables attackers to bypass security restrictions and escalate privileges, posing a significant risk to virtualized environments and cloud infrastructure. Investigation into this issue is ongoing, with a patch expected to be released shortly.
