# Security Update: Trojanized npm Packages Decode C2 IP From Ethereum Recipient Addresses

_2026-08-05 15:28 UTC_

[Source](https://thehackernews.com/2026/08/trojanized-npm-packages-decode-c2-ip.html)

**Devlog Entry: Trojanized npm Packages**

**Date:** August 5, 2026

**Update:** Recent research has revealed that malicious actors are distributing Trojanized npm packages that utilize Ethereum recipient addresses to hide Command and Control (C2) IP addresses. This tactic allows attackers to obfuscate their communication channels, making it challenging for security teams to detect and remediate compromised packages. **Recommendation:** Ensure that security tools and practices are in place to monitor and validate npm package dependencies, and consider implementing additional measures to detect and prevent C2 communication.
