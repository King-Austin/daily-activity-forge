# Security Update: Chinese-Made Zbtlink Routers Ship With Backdoor That Opens Unauthenticated Root Shells

_2026-08-06 08:30 UTC_

[Source](https://thehackernews.com/2026/08/chinese-made-zbtlink-routers-ship-with.html)

**Devlog Entry: Zbtlink Routers Vulnerability**

* Date: 06 August 2026
* Entry: Security Advisory

A recent cybersecurity update has revealed that Chinese-made Zbtlink routers are being shipped with a backdoor that enables unauthenticated root shell access. This vulnerability poses a significant risk to network security, allowing potential attackers to gain unrestricted access to compromised devices. The presence of a pre-installed backdoor raises serious concerns about the integrity of the device's firmware and the manufacturer's security practices.
