# Security Update: Attackers Compile khunt Inside Oracle to Turn SQL Injection Into Windows SYSTEM Access

_2026-08-06 09:50 UTC_

[Source](https://thehackernews.com/2026/08/attackers-compile-khunt-inside-oracle.html)

**Devlog Entry - 2026-08-06**

### Oracle SQL Injection Exploit via khunt

A concerning cybersecurity update has been reported, where attackers are exploiting Oracle databases by compiling a malicious library (`khunt`) inside the database, allowing them to bypass traditional SQL injection defenses and gain Windows SYSTEM access. This technique leverages the Oracle database's ability to compile and execute native code, effectively turning a SQL injection attack into a full system compromise. **High-risk vulnerability identified; further research and testing recommended.**
