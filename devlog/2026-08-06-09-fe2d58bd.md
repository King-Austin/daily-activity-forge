# Security Update: CISA Flags TeamCity CVE-2026-63077 RCE Flaw Under Active Exploitation in the Wild

_2026-08-06 09:10 UTC_

[Source](https://thehackernews.com/2026/08/cisa-flags-teamcity-cve-2026-63077-rce.html)

**Devlog Entry: CVE-2026-63077 TeamCity RCE Flaw**

**Date:** 06 August 2026

**Summary:** A critical Remote Code Execution (RCE) vulnerability (CVE-2026-63077) has been identified in TeamCity, a popular continuous integration and continuous deployment (CI/CD) server. According to CISA, this flaw is currently under active exploitation in the wild, emphasizing the need for immediate patching and mitigation. All users running TeamCity are advised to update to the latest version as soon as possible to prevent potential exploitation.
