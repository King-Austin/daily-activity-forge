# Security Update: Claude Code and Gemini CLI Flaws Let a GitHub Issue Reach CI Workflow Secrets

_2026-08-07 10:33 UTC_

[Source](https://thehackernews.com/2026/08/claude-code-and-gemini-cli-flaws-let.html)

**Devlog Entry: Claude Code and Gemini CLI Vulnerabilities**

**Date:** August 7, 2026

**Summary:**
Recent vulnerabilities in Claude Code and Gemini CLI have been identified, allowing an attacker to access GitHub issue comments and potentially CI workflow secrets. These flaws can be exploited by manipulating the `github.code` context object, enabling unauthorized access to sensitive information. This highlights the importance of monitoring and updating dependencies to prevent such security breaches.
