# Security Update: New WordPress Pre-Auth XSS Could Lead to PHP Code Execution - Patch ASAP

_2026-08-07 13:54 UTC_

[Source](https://thehackernews.com/2026/08/new-wordpress-pre-auth-xss-could-lead.html)

**Devlog Entry: WordPress Pre-Auth XSS Vulnerability**

Date: 08/07/2026

Summary:
A new pre-authentication cross-site scripting (XSS) vulnerability in WordPress has been discovered, allowing attackers to inject malicious JavaScript code that can potentially lead to PHP code execution. This vulnerability requires prompt patching to prevent exploitation, as it affects all WordPress installations prior to the latest version.

**Action Items:**
- Review WordPress codebase for updated patch
- Apply latest WordPress security updates
- Verify installation integrity post-patch
