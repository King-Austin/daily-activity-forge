# Security Update: Metabase Zero-Day Exploited in Wild Allows Admin Access Without Authentication

_2026-08-08 07:55 UTC_

**Devlog Entry - Metabase Zero-Day Vulnerability**

**Date:** August 8, 2026

**Summary:**
A zero-day vulnerability in Metabase has been exploited in the wild, allowing unauthenticated attackers to gain admin access to affected systems. This vulnerability highlights the importance of timely software updates and security patches to prevent exploitation of unpatched vulnerabilities. Metabase users are advised to review their configurations and ensure all software versions are up-to-date to mitigate potential risks.
