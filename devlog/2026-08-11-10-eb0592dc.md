# Security Update: BdThemes Supply Chain Attack Poisons JSON to Create Rogue WordPress Admins

_2026-08-11 10:39 UTC_

[Source](https://thehackernews.com/2026/08/bdthemes-supply-chain-attack-poisons.html)

### DevLog Entry - 08/11/2026

#### BdThemes Supply Chain Attack

A recent cybersecurity update has disclosed a supply chain attack targeting WordPress sites through the BdThemes plugin. The vulnerability allows attackers to inject malicious JSON data, potentially creating rogue WordPress admins. This highlights the importance of regularly monitoring and updating third-party plugins to prevent such supply chain attacks.
