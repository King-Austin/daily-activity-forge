# Security Update: Mozilla Revokes Firefox and Thunderbird Linux Signing Key After Key Lands in Private Repo

_2026-08-11 17:00 UTC_

[Source](https://thehackernews.com/2026/08/mozilla-revokes-firefox-and-thunderbird.html)

**Devlog Entry: Mozilla Signing Key Compromise**

On August 10, 2026, Mozilla revoked its Linux signing key after it was inadvertently added to a private repository, potentially compromising the security of Firefox and Thunderbird on Linux distributions. This vulnerability could have allowed malicious actors to create and distribute tampered versions of these software packages, highlighting the importance of secure key management practices. The incident serves as a reminder of the risks associated with sensitive key exposure and the need for robust security protocols.
