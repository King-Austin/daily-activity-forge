# Security Update: 737 Chrome VPN Extensions Caught Routing Traffic Through Proxies. Check If You Have One

_2026-08-12 16:23 UTC_

[Source](https://thehackernews.com/2026/08/737-chrome-vpn-extensions-caught.html)

**Devlog Entry: Potential Threats in Chrome VPN Extensions**

**Date:** August 12, 2026

I recently came across a cybersecurity update that highlights a significant threat to Chrome users. At least 737 Chrome VPN extensions have been caught routing traffic through proxies, potentially compromising user data and security. This vulnerability underscores the importance of thoroughly vetting third-party extensions and regularly updating Chrome to ensure optimal security and data protection.

**Technical Insight:** 

* **Threat Level:** High
* **Affected Platforms:** Google Chrome
* **Recommendations:** Users are advised to check if they have any of the affected VPN extensions installed and remove them immediately. A thorough review of Chrome extensions is also recommended to prevent similar vulnerabilities in the future.
