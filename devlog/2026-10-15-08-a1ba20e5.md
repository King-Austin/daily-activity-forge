# Security Update: CVE-2026-21558: Linux TCP Stack Remote Code Execution

_2026-10-15 08:15 UTC_

[Source](https://thehackernews.com/2026/10/linux-tcp-patch.html)

A critical flaw in Linux kernel TCP segment reassembly allowed remote code execution via malformed out-of-order packets. Patched across upstream distributions by adding strict boundary verification before buffer copying.
