# Security Update: CVE-2026-24891: Linux Netfilter Conntrack Privilege Escalation

_2026-10-22 02:40 UTC_

[Source](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2026-24891)

An out-of-bounds write in Netfilter connection tracking allowed local unprivileged users to obtain root access via crafted network namespaces. The fix enforces strict size checks on state table extensions.
