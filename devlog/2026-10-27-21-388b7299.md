# Security Update: CVE-2026-28490: Linux eBPF Verifier Bounds Calculation Error

_2026-10-27 21:28 UTC_

[Source](https://kernel.org/security/)

A logic bug in the eBPF verifier's 32-bit register bounds tracking allowed local unprivileged users to achieve kernel read/write primitives. Fixed by correcting sign-extension tracking in the verifier.
