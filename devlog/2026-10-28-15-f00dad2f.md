# Security Update: CVE-2026-22449: Nginx HTTP/3 Memory Corruption Vulnerability

_2026-10-28 15:45 UTC_

[Source](https://nginx.org/en/security_advisories.html)

A heap buffer overflow in Nginx's HTTP/3 QUIC stream parser allowed potential denial of service or arbitrary code execution. Upstream released emergency patches restricting stream header frame lengths.
