# Security Update: Hackers Exploited CVSS 10.0 Hex.pm RCE Flaw to Compromise 6 Package Registry Servers

_2026-11-25 21:54 UTC_

[Source](https://thehackernews.com/2026/11/hackers-exploited-cvss-100-hexpm-rce.html)

Noted a critical exploitation of a CVSS 10.0 remote code execution flaw in Hex.pm, where attackers successfully compromised six package registry servers. This incident underscores the severe supply chain risks inherent in centralized package ecosystems and highlights the urgency for auditing dependencies and implementing strict runtime isolation for build environments.
