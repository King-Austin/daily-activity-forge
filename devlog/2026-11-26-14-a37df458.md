# Security Update: 1Password Hacked, Customer Data and Source Code Stolen in GitHub Account Breach

_2026-11-26 14:36 UTC_

[Source](https://thehackernews.com/2026/11/1password-hacked-customer-data-and.html)

Noted the report of a 1Password breach involving GitHub account compromise, resulting in the exfiltration of customer data and source code. This incident highlights the critical risk of supply-chain attacks via compromised developer credentials and underscores the urgent need for strict least-privilege access controls and hardware-based MFA for all CI/CD and repository management accounts.
