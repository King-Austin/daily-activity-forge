# Security Update: North Korea-Linked PolinRider Poisons Over 7,600 GitHub Repositories to Spread Malware

_2026-11-26 15:25 UTC_

[Source](https://thehackernews.com/2026/11/north-korea-linked-polinrider-poisons.html)

Noting the escalation of the PolinRider campaign, which leverages supply chain attacks to compromise over 7,600 GitHub repositories—a significant vector for propagating malware under North Korean threat actor attribution. This incident underscores the critical need to audit third-party dependencies and implement strict provenance checks in CI/CD pipelines to mitigate risks from poisoned public packages.
