# Security Update: Unpatched Cacti Zero-Day Enables RCE in Just Four HTTP Requests via Guest Access

_2026-11-27 07:09 UTC_

[Source](https://thehackernews.com/2026/11/unpatched-cacti-zero-day-enables-rce-in.html)

Noted the recent disclosure of an unpatched Cacti zero-day that permits remote code execution (RCE) through guest access in just four HTTP requests. This low-friction attack vector poses a significant risk to exposed monitoring instances, underscoring the need to immediately audit access controls and apply mitigations until a vendor patch is released.
