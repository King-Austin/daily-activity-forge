# TIL: My Images Are Dithered

_2026-07-25 13:27 UTC_

[Original Source](https://dead.garden/blog/how-my-images-are-dithered.html)

### Today I Learned

TIL that image dithering, a technique used to reduce color depth in images, can be inadvertently triggered by certain web technologies. According to the article, the culprit behind dithering on `dead.garden` was a combination of a CDN's caching behavior, a poorly optimized image format, and a particular web browser's rendering engine. This highlights the importance of considering the downstream effects of caching, compression, and rendering on image quality when building web applications. Specifically, I need to be aware of potential dithering issues when using CDNs, image formats like WebP, and rendering engines like Skia, especially in scenarios where high-fidelity image display is critical.
