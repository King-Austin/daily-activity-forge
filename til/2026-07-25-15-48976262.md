# Today I Learned (TIL)

TIL about the "Stolen Buttons" security vulnerability (https://anatolyzenkov.com/stolen-buttons) which allows attackers to bypass browser's Same-Origin Policy by abusing the `beforeunload` event and a timing-based side-channel attack on the `navigator.sendBeacon` API. This technique enables malicious scripts to steal sensitive data from another origin, highlighting the importance of carefully evaluating the security implications of modern web APIs and events, and demonstrating the need for robust browser-based countermeasures to protect against such attacks.
