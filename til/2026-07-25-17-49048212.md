# TIL: Engineering management after the cost of code collapsed

_2026-07-25 17:13 UTC_

[Original Source](https://karimjedda.com/engineering-management-after-cost-of-code-collapse/)

**Today I Learned (TIL)**

TIL that the concept of 'Cost of Code' - a metric that measures the trade-offs between development speed, code quality, and cost - has been largely discredited. This has significant implications for software development teams, as it means traditional engineering management approaches focusing on minimizing 'Cost of Code' may no longer be effective. I'm left wondering if our existing code review processes, testing strategies, and code organization practices are still relevant in a world without a direct, quantifiable measure of 'Cost of Code'.
