# TIL: A shell colon does nothing. Use it anyway

_2026-07-26 05:59 UTC_

[Original Source](https://refp.se/articles/your-shell-and-the-magic-colon)

**Today I Learned (TIL)**

TIL about the often-overlooked shell colon (`:`) and its potential implications for software development. According to the article, when used in shell commands, the colon serves as a separator for options or flags, but when used in isolation, it effectively does nothing. However, the author suggests intentionally using it to improve code readability and make commands more visually distinct. This subtle technique can promote better shell script maintainability and reduce the likelihood of typos, as it provides a clear visual cue for separation between commands and their options. I'll keep this in mind when crafting shell scripts in the future.
