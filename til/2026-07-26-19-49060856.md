# TIL: Decker

_2026-07-26 19:15 UTC_

[Original Source](https://beyondloom.com/decker/)

**TIL (Today I Learned)**

I came across an interesting project called Decker (https://beyondloom.com/decker/), which implements a novel approach to building web applications by combining the benefits of serverless functions and traditional application servers. The key insight is that Decker allows developers to write serverless functions that can execute on the client-side, leveraging the power of modern web browsers. This concept has the potential to change the way we think about scalability, latency, and security in web development, as it enables a seamless integration of serverless compute with traditional HTTP requests. I'm excited to explore this idea further and consider how it might be applied to tackle specific pain points in our own projects.
