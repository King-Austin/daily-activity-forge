### TIL: Scriptc by Vercel - No JavaScript Engine in Binary

Today I learned about [Scriptc](https://github.com/vercel-labs/scriptc), a TypeScript-to-Native compiler from Vercel Labs. This project has the potential to revolutionize the way we think about native application development, as it allows for the compilation of TypeScript code into native machine code without relying on a JavaScript engine in the binary. This implies that applications built with Scriptc can potentially offer better performance and security characteristics, as they don't have to worry about the overhead of a JavaScript runtime environment. Furthermore, Scriptc's ability to compile TypeScript code directly to native code opens up possibilities for more efficient code generation and potentially reduced binary sizes, which could be beneficial for certain types of applications.
