# TIL: DConf 2026 in London

_2026-07-27 23:18 UTC_

[Original Source](https://dconf.org/2026/index.html)

**TIL (28 Jul 2026)**

Attended a link to the DConf 2026 conference in London (https://dconf.org/2026/index.html) and noted that a key takeaway is the increasing use of the C++ programming language in modern software development. The conference focuses on the D language, a systems programming language that compiles to C++ and has a similar set of features and a growing community. Understanding the overlap and similarities between D and C++ is essential for developers working in systems programming or high-performance applications. I'll have to keep an eye on the DConf 2026 talks and see how the lessons learned can be applied to my projects.
