# TIL: Button vs Link Semantics

TIL that the distinction between a button and a link is more than just a visual difference, but also affects accessibility and usability. A link is typically a reference to an external resource, whereas a button is an interactive element that triggers an action. This distinction is often overlooked in web development, leading to inconsistent user experiences. To improve my code, I'll make sure to use the `button` element for form submissions and other interactive actions, rather than relying on links with JavaScript click handlers, to ensure proper keyboard navigation and accessibility features are available to users.
