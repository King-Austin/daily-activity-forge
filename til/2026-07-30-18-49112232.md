# TIL: Stacked PRs are now live on GitHub

_2026-07-30 18:41 UTC_

[Original Source](https://github.blog/changelog/2026-07-30-stacked-pull-requests-are-now-in-public-preview/)

### Today I Learned

TIL that GitHub has enabled stacked pull requests in public preview. This change allows multiple pull requests to be shown as a single entity, potentially simplifying the review process by grouping related changes. From a technical standpoint, I'm curious to see how this affects the way users interact with the Pull Request API, particularly in terms of pagination and filtering. Stacked pull requests may also impact CI/CD workflows, as automated testing and validation could be triggered on the parent PR, rather than individual child PRs.
