# TIL: Tailscale didn't stop the Hugging Face intrusion

_2026-07-31 19:14 UTC_

[Original Source](https://tailscale.com/blog/hugging-face-intrusion)

**TIL: Zero Trust Network Access (ZTNA) is not foolproof**
I came across the Tailscale blog post on the Hugging Face intrusion, which highlights the limitations of Zero Trust Network Access (ZTNA) solutions. Specifically, the incident demonstrates how an attacker can bypass Tailscale's ZTNA security features by targeting the user's device, exploiting a vulnerability in the user's credentials, and then leveraging the compromised user's access to breach the network. This emphasizes the need for multi-layered security and highlights the importance of considering endpoint security, user education, and credential management when evaluating the effectiveness of ZTNA solutions.
