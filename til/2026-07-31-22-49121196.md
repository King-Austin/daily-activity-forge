# TIL (2023-07-31)

TIL about Progressive Web Components (PWC) from Ariel Salminen's article, which seems to be a game-changer for web development. PWC combines the benefits of Web Components and Progressive Web Apps, allowing developers to create web applications that can be installed and run offline, with offline support, web app capabilities, and seamless updates. The technical takeaway is that PWC can be achieved using the `@webcomponents/pwa-elements` library, which provides a set of pre-built elements for building PWAs. This means developers can now focus on building web applications with offline support and web app capabilities without needing to worry about the underlying plumbing, making it easier to create high-quality web experiences that rival native apps.
