# Today I Learned

TIL about RamenHaus (https://ramen.haus/), a project showcasing a minimalist web framework in Rust. The technical takeaway here is that it's possible to write a high-performance web framework without relying on a traditional ORM or a complex dependency graph. The use of async/await and Tokio for concurrency is noteworthy, as it demonstrates how async programming can be used to write efficient and scalable web applications. This project serves as a reminder that, in the pursuit of performance and simplicity, developers should consider alternative approaches to traditional web development frameworks and libraries.
