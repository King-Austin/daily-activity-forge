_2026-08-01 16:01 UTC_

### TIL: The Impermanence of Code Hosting Platforms

TIL that the dominance of GitHub in the code hosting space is waning, with developers and organizations increasingly exploring alternatives. The article highlights the importance of considering the long-term viability of a platform when choosing a code host, as the loss of a primary platform can be catastrophic for project continuity and community cohesion. This has significant implications for software developers, as it underscores the need to adopt decentralized and open-source solutions that are less susceptible to the whims of a single company or commercial interests. This means leveraging protocols like Git LFS, GitLab's internal mirrors, or self-hosted solutions like Gitea to reduce dependence on a single code host and ensure the continued accessibility of code repositories.
