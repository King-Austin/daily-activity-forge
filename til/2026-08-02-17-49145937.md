# TIL: Show HN: Kakehashi – Experimental userspace to run macOS binaries on Linux ARM

_2026-08-02 17:04 UTC_

[Original Source](https://github.com/wie-project/kakehashi)

### Today I Learned: Cross-Compatibility via Binary Translation

TIL that the Kakehashi project is experimenting with a userspace solution to run macOS binaries on Linux ARM, leveraging binary translation. This approach has significant implications for software compatibility and portability across different operating systems and architectures. The technical takeaway here is that binary translation can be a viable alternative to traditional recompilation or emulation, enabling developers to run foreign binaries on unfamiliar systems. This opens up possibilities for repurposing existing macOS codebases for Linux, and could potentially bridge the gap between different ecosystems, but also raises concerns about performance and compatibility trade-offs.
