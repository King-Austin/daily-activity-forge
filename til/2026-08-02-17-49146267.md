# TIL: NixOS on DGX Spark
Today I learned that it's now possible to run NixOS on the NVIDIA DGX Spark, a high-performance computing platform. The `nixos-dgx-spark` project by Graham demonstrates the feasibility of leveraging Nix's declarative package manager and NixOS's system configuration management on a powerful, GPU-accelerated system. This development has implications for researchers and developers who rely on reproducibility, isolation, and ease of configuration in their workflows. By applying NixOS's principles to a high-performance computing environment, users can now more easily manage complex dependencies, reproduce experiments, and scale their applications.
