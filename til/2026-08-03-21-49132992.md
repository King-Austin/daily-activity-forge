# TIL: 200ms Click Delay in Web Browsers

Today I learned about the phenomenon of a 200ms click delay in web browsers, a common anti-flicker technique used to prevent multiple clicks being registered when a user rapidly clicks a button. This delay can introduce usability issues, particularly in applications that require precise timing, such as gaming or precision editing tools. I'll keep in mind that this browser behavior can affect the performance of my applications and plan accordingly, potentially using techniques like debouncing or custom click event handling to bypass the default browser behavior.
