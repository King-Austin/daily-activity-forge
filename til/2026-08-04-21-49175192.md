# TIL: Thanks FedEx, This Is Why We Keep Getting Phished (2024)

_2026-08-04 21:26 UTC_

[Original Source](https://www.troyhunt.com/thanks-fedex-this-is-why-we-keep-getting-phished/)

TIL that phishing attacks can be facilitated by seemingly innocuous third-party services. A recent article highlights how FedEx, via an API integration, inadvertently provided attackers with sensitive information, including email addresses and real names of customers, which were then used to craft targeted phishing emails. This serves as a reminder that even well-intentioned, publicly-facing services can introduce security risks when not properly vetted or secured, emphasizing the importance of evaluating the security posture of any external API or service integration before integrating it into our applications.
