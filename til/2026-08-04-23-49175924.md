# TIL: DuckDB – Data power tools for your laptop, now in Clojure (2023)

_2026-08-04 23:26 UTC_

[Original Source](https://techascent.com/blog/just-ducking-around.html)

**Today I Learned (TIL)**

TIL about DuckDB, a column-store database designed for local data analysis, now available in Clojure. This development is notable, as it expands DuckDB's reach to the Lisp-based language community, potentially making it easier for Clojure developers to leverage in-memory analytics and data processing capabilities. The fact that DuckDB is built with a focus on performance and low latency also implies that this Clojure integration may offer a competitive alternative to existing data processing tools, such as Apache Arrow or Hypha, for tasks like data exploration, aggregation, and data science workloads.
