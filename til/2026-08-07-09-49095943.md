# TIL: Scanner-Based Parsing is a Viable Alternative to Traditional Parsing Techniques

I came across an insightful article on Hacker News today, 'Parsers don't have to be complicated' by Bojan Karadzic, which highlighted the simplicity and effectiveness of scanner-based parsing. I learned that by decoupling the lexer (scanner) from the parser, you can create a more modular and easier-to-maintain parsing system. This approach can be particularly beneficial for developing recursive descent parsers with multiple input formats, as it allows for the reuse of the scanner across different parser implementations. This technique is definitely worth considering for my future parser implementation projects, as it offers a refreshing alternative to the traditional parsing methods that I've been using so far.
