# Today I Learned (TIL)

TIL about [eclipsefan.org](https://eclipsefan.org), an open-source interactive map for visualizing the Aug 12 total solar eclipse. This project is a great example of using web mapping technologies (e.g. Leaflet.js) to create immersive and data-driven visualizations. By leveraging libraries like Leaflet and GeoJSON, developers can easily integrate complex geospatial data and interactive controls into web applications. One technical takeaway from this project is the use of tile layers (e.g. OpenStreetMap) to provide a seamless map experience, and the integration of various data layers (e.g. eclipse path, shadow simulation) using techniques like vector tile rendering and marker clustering. This demonstrates the power of open-source mapping tools and the creative possibilities they enable for developers and data scientists.
