# Today I Learned

TIL that a native x64 port of Microsoft Word 1.1a for Windows is available as an open-source project on GitHub. This project, while primarily a nostalgic curiosity, offers valuable insights into the inner workings of legacy applications and the challenges of reverse engineering and modernizing outdated codebases. The fact that this ancient version of Word, written in 16-bit assembly and C, can be successfully compiled and run on contemporary 64-bit systems speaks to the power and flexibility of modern compilers and the x64 architecture. This project serves as a reminder that, with enough dedication and technical expertise, it may be possible to revitalize and adapt legacy code, making it a fascinating case study for developers interested in software preservation and the art of reverse engineering.
