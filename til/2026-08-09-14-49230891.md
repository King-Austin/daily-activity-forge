# TIL: Show HN: A Project Oberon System version running on RISC-V instead of RISC-5

_2026-08-09 14:23 UTC_

[Original Source](https://github.com/rochus-keller/OberonSystem/tree/op2-rv32)

**Today I Learned**
TIL that it's possible to port a 40-year-old operating system like Project Oberon to a modern ISA like RISC-V, demonstrating the flexibility and versatility of software architecture. This feat is impressive given the original Oberon System was written for a RISC-5 processor, and the migration to RISC-V (specifically rv32) requires adapting to a fundamentally different instruction set. This experiment highlights the importance of abstraction, modular design, and the ability to separate hardware-dependent code from application logic, making it easier to port software to different platforms.
