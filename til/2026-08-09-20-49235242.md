# TIL: Deletes all instances of Microsoft's GDID and prevents minting of new ones

_2026-08-09 20:39 UTC_

[Original Source](https://github.com/yegors/deGDID)

**Today I Learned (TIL)**

TIL about the `deGDID` project by yegors, a tool that deletes all instances of Microsoft's Globally Unique Identifier (GUID) and prevents minting of new ones. This caught my attention because it highlights the potential security implications of hardcoding or storing Microsoft's GUIDs, which can create vulnerabilities if leaked or compromised. As a developer, I'll keep in mind that relying on proprietary identifiers, especially when they're tied to a specific vendor, can introduce risks that outweigh the convenience of using them. Instead, I'll consider using alternative identifier schemes or libraries that provide more control and flexibility, such as UUIDs or Snowflakes. This serves as a reminder to carefully evaluate the trade-offs between ease of use and security when making technical decisions.
