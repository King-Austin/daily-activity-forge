# TIL: Run Android ARM64 VR APKs on Apple Vision Pro

_2026-08-10 05:25 UTC_

[Original Source](https://github.com/shinyquagsire23/Klepton)

### Today I Learned

TIL that the Klepton project on GitHub is successfully running Android ARM64 VR APKs on Apple Vision Pro using a combination of Rosetta 2 and the Android Runtime (ART) environment. This achievement has significant implications for cross-platform development and virtual reality (VR) applications. Specifically, it highlights the potential for exploiting emulation layers, such as Rosetta 2, to bypass traditional architecture-based compatibility barriers, and demonstrates the feasibility of using existing Android APKs with minimal modifications to support new platforms. As a developer, this raises interesting questions about the future of platform-agnostic development and the role of emulation in bridging ecosystem divides.
