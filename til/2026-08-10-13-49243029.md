# TIL: 50k Boat Names

_2026-08-10 13:11 UTC_

[Original Source](https://www.beautifulpublicdata.com/boat-names/)

**Today I Learned (TIL)**

TIL about the "50k Boat Names" dataset, a collection of ~50,000 unique boat names scraped from the USCG database. This resource has the potential to be a useful test case for various natural language processing (NLP) and string manipulation tasks, such as name entity recognition, similarity detection, and data deduplication. For instance, I could use this dataset to experiment with approximate string matching algorithms, like Levenshtein distance or Jaro-Winkler, to identify near-duplicate boat names or generate new name suggestions. Additionally, analyzing the characteristics of boat names (e.g., length, word frequency, prefix/suffix patterns) could provide insights into the structure of other types of text data, like user-generated content or product names.
