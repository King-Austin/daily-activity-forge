# TIL: Gloomberb's Use of Rust and WebAssembly

Today I came across the Gloomberb project (https://gloom.sh/) on Hacker News, which showcases a Rust-based implementation of a web browser backend using WebAssembly (WASM). What caught my attention was the potential to leverage Rust's performance and concurrency capabilities in a web context, which could lead to significant improvements in web app responsiveness and scalability. This concept resonates with my own interests in exploring WASM for high-performance web applications, and I'm intrigued by the possibility of using Rust as a compilation target for WASM, allowing for more efficient memory management and parallelization. I'll need to dive deeper into the Gloomberb source code to fully appreciate its architecture and design decisions.
