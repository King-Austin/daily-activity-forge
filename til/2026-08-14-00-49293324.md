# TIL: Bluesky Protocol Services

_2026-08-14 00:31 UTC_

[Original Source](https://atproto.com/blog/introducing-bluesky-protocol-services)

**Today I Learned (TIL)**

TIL about the Bluesky Protocol Services, a new decentralized protocol from the makers of Notes app and Mastodon, which aims to enable interoperability between different social media platforms. This development has significant implications for software developers, as it could pave the way for a more decentralized and open web, where data can be seamlessly shared and interacted with across different services. From a technical perspective, this might involve leveraging Bluesky's open protocols to build decentralized social media applications, integrating Bluesky's APIs for data exchange, and designing systems that can adapt to the evolving Bluesky ecosystem, potentially incorporating features like token-based authentication and data federation.
