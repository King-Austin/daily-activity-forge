# TIL: RustDesk now supports true unattended remote access on Wayland

_2026-08-14 16:48 UTC_

[Original Source](https://rustdesk.com/blog/unattended-remote-access-wayland/)

### Today I Learned

TIL that RustDesk now supports true unattended remote access on Wayland, which has significant implications for developers working on desktop applications that use this display server protocol. This development is particularly notable because it allows for seamless, unattended remote access, effectively eliminating the need for users to interact with their local machine before a remote session can be established. This capability, enabled by RustDesk's integration with Wayland, opens up opportunities for developers to create more robust, automated testing and CI/CD pipelines, as well as more advanced remote support and collaboration tools.
