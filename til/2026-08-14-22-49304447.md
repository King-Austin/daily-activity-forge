# TIL: Everything is about to "go dark"

_2026-08-14 22:03 UTC_

[Original Source](https://blog.cryptographyengineering.com/2026/08/14/everything-is-about-to-go-dark/)

### Today I Learned (TIL)

TIL that a potential global outage of the Internet's underlying infrastructure could be caused by a widely held cryptographic key being compromised. The blog post by Matt Green highlights the risks associated with the SHA-1 hash function being used in the Internet's Domain Name System (DNS) key signing key (KSK) rollover process. Specifically, I learned that if the new KSK is not widely accepted before the old one expires, it could lead to a global DNS outage. This has implications for software developers who rely on DNS for service discovery, load balancing, and other critical infrastructure components. It is crucial for developers to be aware of this potential threat and plan accordingly, potentially by implementing fallback mechanisms or using alternative DNS providers.
