# Today I Learned

TIL that the article "RISC-V: They Should Have Known Better" by Dmitry Grigoriev highlights potential vulnerabilities in the RISC-V architecture. Specifically, I learned that the `csr` instructions in RISC-V can be used to access arbitrary memory locations, including the supervisor stack, potentially allowing for privilege escalation attacks. This raises concerns about the security implications of using RISC-V in high-assurance systems. To mitigate this risk, developers should carefully evaluate their use of `csr` instructions and consider implementing additional security measures, such as access control checks, to prevent potential attacks.
