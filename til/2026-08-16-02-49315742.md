# TIL: Show HN: Mic Drop, a real-time multiplayer karaoke game

_2026-08-16 02:36 UTC_

[Original Source](https://www.micdrop.gg/)

### Today I Learned

TIL about `Mic Drop`, a real-time multiplayer karaoke game, which showcases a modern web application built with WebRTC and Node.js. The technical implications of this project are noteworthy, particularly in how it leverages WebRTC for peer-to-peer audio streaming, allowing for low-latency synchronization between players. This approach bypasses traditional server-based audio processing, reducing latency and enabling a more immersive experience. Notably, the project also employs WebSockets and Socket.IO for real-time communication between the game server and clients, demonstrating how to implement efficient, scalable, and real-time communication in modern web applications.
