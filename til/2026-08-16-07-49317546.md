# TIL: Show HN: Laptop is the last place your secrets are still in plaintext

_2026-08-16 07:06 UTC_

[Original Source](https://github.com/jitpass/jit)

**TIL: JIT-compiled secrets are not secure**

I came across an interesting project on GitHub, `jit`, which compiles secrets into a native binary, making them appear as plaintext in laptop logs. This got me thinking about the implications for secure data storage. If an attacker gains access to a user's laptop, they may be able to extract plaintext secrets, even if they're stored in a supposed "secure" location. This highlights the importance of considering the entire data flow, from storage to execution, when designing secure systems. It also underscores the need for using secure environments, such as encrypted containers or remote execution, to protect sensitive information.
