# TIL: Ask HN: Do you know of any company that went back to hand-written code?

_2026-08-16 12:07 UTC_

[Original Source](https://news.ycombinator.com/item?id=49318906)

**Today I Learned (TIL)**
================================

TIL that despite the widespread adoption of automated tools and CI/CD pipelines, some companies are reconsidering the use of handwritten code in certain contexts. This trend could have implications for software development, such as a shift towards more manual testing and validation of code, potentially leading to more robust, fault-tolerant systems. It may also prompt developers to revisit the principles of code simplicity, readability, and maintainability, as well as the value of human intuition in software development.
