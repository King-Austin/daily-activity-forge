# TIL: Protobuf has LSP support. You're welcome

_2026-08-16 19:38 UTC_

[Original Source](https://buf.build/blog/protobuf-lsp)

**Today I Learned (TIL)**

I just learned about the recent addition of Language Server Protocol (LSP) support in Protocol Buffers (protobuf). This news has significant implications for developers who use protobuf in their projects, as it enables features like code completion, diagnostics, and code refactoring. Specifically, I noted that this integration leverages the buf CLI tool, which allows for seamless integration with popular IDEs and editors such as VS Code. This development should streamline the development process for protobuf-based projects, making it easier to maintain and scale complex data serialization and deserialization logic. I'll be keeping an eye on the buf CLI tool and exploring how to implement this in my own projects.
