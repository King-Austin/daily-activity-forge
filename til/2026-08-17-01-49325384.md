# TIL: Rhombus 1.1 is now available

_2026-08-17 01:23 UTC_

[Original Source](https://blog.racket-lang.org/2026/08/rhombus-v1.1.html)

### Today I Learned (TIL)

TIL about Rhombus 1.1, a new version of a high-performance, in-memory graph database. The implications of this release are significant for developers working with complex graph data structures. Rhombus's ability to efficiently store and query large graphs using a combination of in-memory indexing and novel query algorithms could enable new use cases in areas like social network analysis, recommendation systems, and fraud detection. As a developer, I'm particularly interested in exploring how Rhombus's data model, which uses a rhombus (a quadrilateral with all sides of equal length) as the fundamental unit of data, might influence the design of my own applications and how I approach graph data modeling in the future.
