# TIL: Vector search: Inverted File Index with Product Quantization (IVF-PQ)

_2026-10-19 04:17 UTC_

[Original Source](https://arxiv.org/abs/1109.0880)

IVF-PQ clusters high-dimensional vectors into Voronoi cells and compresses residual vectors into short byte codes using product quantization, enabling billion-scale search with minimal memory footprint.
