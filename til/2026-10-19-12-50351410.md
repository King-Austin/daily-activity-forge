# TIL: Linux VFS dentry cache and lookup performance

_2026-10-19 12:52 UTC_

[Original Source](https://www.kernel.org/doc/html/latest/filesystems/vfs.html)

The Virtual Filesystem (VFS) dentry cache (dcache) caches path name lookups in RAM using an RCU-protected hash table, drastically reducing disk inode queries for hot directory trees.
