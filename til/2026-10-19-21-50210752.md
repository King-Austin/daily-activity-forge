# TIL: SQLite Write-Ahead Logging (WAL) Concurrency

_2026-10-19 21:28 UTC_

[Original Source](https://www.sqlite.org/wal.html)

Today I learned that SQLite WAL mode allows concurrent readers to proceed uninterrupted while a single writer appends changes to the `-wal` file. Readers read from both the main database and the WAL index, eliminating writer-starvation of reader queries.
