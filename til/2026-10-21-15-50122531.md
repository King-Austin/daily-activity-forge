# TIL: Encrypted Client Hello (ECH) in TLS

_2026-10-21 15:41 UTC_

[Original Source](https://datatracker.ietf.org/doc/html/draft-ietf-tls-esni-17)

Today I learned that ECH encrypts the Server Name Indication (SNI) inside a client-generated public key fetched via DNS HTTPS resource records, preventing network eavesdroppers from discovering which domain a user is visiting.
