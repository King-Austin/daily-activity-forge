# TIL: Git Packfile Delta Compression and Cruft Packs

_2026-10-21 21:45 UTC_

[Original Source](https://github.blog/2022-09-13-scaling-gits-garbage-collection/)

Today I learned how Git uses delta compression to store file modifications as diffs against similar historical blobs. Recent Git releases introduce cruft packs to prevent unreachable loose objects from fragmenting the filesystem during garbage collection.
