# TIL: Branch Prediction and the Branch Target Buffer (BTB)

_2026-10-22 06:33 UTC_

[Original Source](https://en.wikipedia.org/wiki/Branch_target_predictor)

Today I learned how modern CPUs predict conditional branch destinations using 2-bit saturating counters and global branch history registers. Branch mispredictions flush the processor pipeline, causing a penalty of 15 to 20 clock cycles.
