# TIL: Linux epoll Edge-Triggered vs Level-Triggered

_2026-10-22 21:22 UTC_

[Original Source](https://man7.org/linux/man-pages/man7/epoll.7.html)

Today I learned that with `EPOLLET` (edge-triggered), `epoll_wait` only notifies when the file descriptor changes state. Applications must loop with non-blocking reads until `EAGAIN` to avoid missing incoming data.
