# TIL: Zero-copy networking with splice() and vmsplice()

_2026-10-23 12:57 UTC_

[Original Source](https://man7.org/linux/man-pages/man2/splice.2.html)

The `splice()` system call moves data between two file descriptors (such as a network socket and a pipe) without copying bytes between kernel and user space, eliminating memory bus traffic.
