# TIL: Memory alignment and cache line padding in modern CPUs

_2026-10-24 02:37 UTC_

[Original Source](https://lwn.net/Articles/252125/)

Today I learned about how hardware cache lines (typically 64 bytes) affect data structure layout. Misaligned structs or sharing variables across threads within the same cache line leads to false sharing, which causes high cache invalidation traffic. Adding explicit padding or aligning structures to cache-line boundaries with `alignas(64)` can produce 2-3x throughput improvements on multi-threaded workloads.
