# TIL: TLS 1.3 0-RTT Session Resumption Risks

_2026-10-24 21:45 UTC_

[Original Source](https://datatracker.ietf.org/doc/html/rfc8446#section-2.3)

Today I learned that while TLS 1.3 0-RTT allows clients to send application data on the first flight to reduce connection latency, it does not provide forward secrecy and is vulnerable to replay attacks. Web applications must ensure non-idempotent HTTP methods (POST, PUT, DELETE) are rejected over early data.
