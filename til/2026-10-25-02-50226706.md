# TIL: Go runtime work-stealing scheduler design

_2026-10-25 02:11 UTC_

[Original Source](https://rakyll.org/scheduler/)

Today I learned how Go's M:N scheduler handles goroutines across OS threads. Each processor (P) maintains a local run queue (size 256), and an idle thread will attempt to steal half the work from another processor's queue before checking the global queue or sleeping, minimizing lock contention.
