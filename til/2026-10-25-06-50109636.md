# TIL: Raft consensus: Log Compaction and Snapshotting

_2026-10-25 06:40 UTC_

[Original Source](https://raft.github.io/raft.pdf)

Today I learned how Raft prevents its write-ahead log from growing unbounded. When a snapshot is taken, the state machine serializes its state, and all log entries up to that index are discarded. If a lagging follower falls too far behind, the leader streams the entire snapshot via `InstallSnapshot` RPC instead of replaying individual log entries.
