# TIL: Linux cgroups v2 unified hierarchy

_2026-10-25 09:38 UTC_

[Original Source](https://docs.kernel.org/admin-guide/cgroup-v2.html)

Today I learned that cgroups v2 replaces the separate controller trees of v1 with a single unified hierarchy. This eliminates inconsistent thread-group memberships across controllers and enables proper resource accounting for out-of-memory killing and buffered writeback memory attribution.
