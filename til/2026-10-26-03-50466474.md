# TIL: Linux epoll event loop starvation prevention

_2026-10-26 03:55 UTC_

[Original Source](https://man7.org/linux/man-pages/man7/epoll.7.html)

When reading from high-bandwidth streams in edge-triggered mode, processing loops must enforce a maximum byte limit before yielding control back to `epoll_wait` to avoid starving other active file descriptors.
