# TIL: B-tree branch factor and disk sector alignment

_2026-10-26 08:47 UTC_

[Original Source](https://en.wikipedia.org/wiki/B-tree)

In relational database storage engines, B-tree node size is tuned to match the underlying disk block or filesystem cluster size (e.g., 4KB or 8KB). A node branching factor of 100-200 provides shallow trees with logarithmic height of 3-4 levels for billions of keys.
