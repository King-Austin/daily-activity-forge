# TIL: Memory Fences and the Total Store Order (TSO) Model

_2026-10-26 12:41 UTC_

[Original Source](https://www.cl.cam.ac.uk/~pes20/weakmemory/index.html)

Today I learned that x86-64 processors enforce a Total Store Order memory model where stores are not reordered with older stores, but store-load reordering can still occur through store buffers. On ARM architectures with relaxed ordering, explicit `dmb` (data memory barrier) instructions are necessary to synchronize atomic operations across cores.
