# TIL: Redis Memory Allocation and jemalloc Arenas

_2026-10-26 21:24 UTC_

[Original Source](https://redis.io/docs/management/optimization/memory-optimization/)

Today I learned that Redis relies on jemalloc's memory arenas to minimize fragmentation. Setting `activedefrag yes` allows Redis to scan and relocate keys in memory pages with high fragmentation without blocking the event loop.
