# TIL: Linux SO_REUSEPORT and load distribution across worker threads

_2026-10-29 01:16 UTC_

[Original Source](https://lwn.net/Articles/542629/)

The `SO_REUSEPORT` socket option allows multiple listening sockets to bind to the same IP and port. The Linux kernel distributes incoming SYN packets across sockets using a hash of the 4-tuple.
