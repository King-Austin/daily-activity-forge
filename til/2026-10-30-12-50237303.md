# TIL: Database Deadlock Detection with Wait-For Graphs

_2026-10-30 12:19 UTC_

[Original Source](https://en.wikipedia.org/wiki/Wait-for_graph)

Today I learned that transactional database engines maintain a directed wait-for graph where nodes represent transactions and edges represent lock requests. Cycle-detection algorithms periodically run to abort the transaction with the lowest rollback cost.
