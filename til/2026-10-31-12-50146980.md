# TIL: eBPF packet processing with XDP

_2026-10-31 12:30 UTC_

[Original Source](https://prototype-kernel.readthedocs.io/en/latest/networking/XDP/)

Today I learned that eBPF programs attached to eXpress Data Path (XDP) execute directly at the network driver level before the Linux network stack even allocates an `sk_buff`. This enables line-rate packet filtering, DDoS mitigation, and load balancing with near-zero kernel overhead.
