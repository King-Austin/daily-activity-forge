# TIL: Memory ordering semantics: Acquire and Release fences

_2026-10-31 21:15 UTC_

[Original Source](https://en.cppreference.com/w/cpp/atomic/memory_order)

Acquire and release memory semantics provide synchronization without requiring full sequential consistency barriers. An acquire operation prevents subsequent memory operations from being reordered before it, while a release operation prevents preceding operations from being reordered after it.
