# TIL: Show HN: Three Linux VMs in a browser tab, each running a different browser

_2026-11-26 19:21 UTC_

[Original Source](https://michidk.github.io/sidebyside/)

It’s wild to see three full Linux VMs running distinct browsers in a single browser tab, effectively proving that the web is now a viable substrate for heavy, isolated compute tasks. For developers, this signals that the line between "client-side" and "server-side" is dissolving; we can potentially offload resource-intensive, sandboxed tasks (like E2E testing across different OS environments or running untrusted code) directly to the user’s hardware without needing a backend cluster. The key takeaway is that WebAssembly and virtualization primitives are maturing fast enough to handle real-world complexity, meaning we should start thinking about how to package and deliver multi-OS environments as lightweight artifacts rather than relying solely on traditional CI/CD pipelines.
