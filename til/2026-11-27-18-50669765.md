# TIL: Convex skills send the user's app idea to a remote server without telling them

_2026-11-27 18:56 UTC_

[Original Source](https://github.com/convex/convex-backend-skill/issues/64)

**TIL:** The `convex-backend-skill` controversy highlights a critical trust gap in AI-assisted development workflows, specifically regarding how LLM agents interact with external infrastructure. The issue reveals that the skill implicitly routes user prompts to a remote Convex server for processing without explicit consent or transparent telemetry, effectively treating the user's application idea as data for third-party analysis. For developers integrating agentic coding tools, this is a stark reminder that "magic" CLI commands or IDE plugins often hide significant network I/O and data exfiltration risks behind the scenes; before adopting any new AI dev tool, it’s imperative to audit the underlying prompts, network calls, and data retention policies to ensure you aren’t inadvertently leaking proprietary logic or business ideas to a vendor’s backend just to generate boilerplate.
