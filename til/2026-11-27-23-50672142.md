# TIL: Source Control from Hell

_2026-11-27 23:27 UTC_

[Original Source](https://frantic.im/git/)

Read "Source Control from Hell" (https://frantic.im/git/), which details a malicious Git repo that exploits the `GIT_DIR` environment variable and core.hooksPath to execute arbitrary code during a simple `git clone`. It’s a stark reminder that treating `git` as a passive data retrieval tool is a security blind spot; since Git executes hooks stored in the repository itself, cloning untrusted sources is effectively running untrusted code with your user permissions. The takeaway is to never clone from unknown or unvetted sources without sandboxing, and to audit your local `core.hooksPath` configuration to ensure you’re not inadvertently pointing to a directory writable by malicious payloads.
