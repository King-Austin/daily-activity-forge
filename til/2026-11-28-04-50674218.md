# TIL: Unkernel: Real Linux kernel, compiled to WebAssembly

_2026-11-28 04:13 UTC_

[Original Source](https://unkernel.dev)

**TIL: Unkernel**

Running a full Linux kernel in WebAssembly (`unkernel.dev`) is a game-changer for reproducible CI environments and secure multi-tenant containerization, effectively eliminating the traditional "host kernel" attack surface. The key technical takeaway is that this isn't just a QEMU emulation hack; it’s a native compilation of the kernel to Wasm, which means you get near-native performance for system calls and memory management while gaining the sandboxing benefits of the Wasm runtime. This opens the door to running untrusted code in isolated, lightweight environments on the browser or edge nodes without the overhead of full VMs, potentially replacing Docker for many use cases where strict isolation is required but performance is still critical.
