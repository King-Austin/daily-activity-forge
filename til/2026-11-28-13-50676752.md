# TIL: GGUF LLM Models with Hidden Malware on Hugging Face Reached 2400 Victims

_2026-11-28 13:45 UTC_

[Original Source](https://malspark.com/blog/malicious-gguf-models-hugging-face/)

I was reading about the wave of malicious GGUF models on Hugging Face that compromised 2,400 users and it’s a stark reminder that the "supply chain" attack surface has expanded beyond just Python packages to binary artifacts. The technical takeaway is that GGUF is just a container format; if you’re loading these files via `llama.cpp` or similar inference engines, you’re executing arbitrary CPU instructions determined by the file’s metadata and tensor data, meaning a compromised model isn’t just bad weights—it’s a potential RCE vector. This reinforces that treating model files with the same security scrutiny as executable binaries (checksums, signed releases, and sandboxed inference environments) is no longer optional, especially when pulling from community repositories where trust is implicit.
